# Project_Python
Данный репозиторий создан для обучения языку программирования Python
Установка Python 

1)	Для начала перейдем на официальный сайт Python - https://www.python.org/<img width="773" height="514" alt="image" src="https://github.com/user-attachments/assets/4852c0f5-fb68-4331-ab71-a12fe5968799" />)
3)	После наводим на кнопку Downloads и выбираем версию python  
4)	Открываем установочный файл и выбираем «Add python to PATH»
5)	После идем далее по установке. 
6)	Чтобы проверить установился Python на компьютер – достаточно проверить в поиске его наличие  
7)	Далее устанавливаем Visual Studio Code с официального сайта - https://code.visualstudio.com/download/
Никаких особенностей в установке нет.

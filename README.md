# Project_Python
Данный репозиторий создан для обучения языку программирования Python
Установка Python 

1)	Для начала перейдем на официальный сайт Python - https://www.python.org/
2)	После наводим на кнопку Downloads и выбираем версию python  
3)	Открываем установочный файл и выбираем «Add python to PATH»
4)	После идем далее по установке. 
5)	Чтобы проверить установился Python на компьютер – достаточно проверить в поиске его наличие  
6)	Далее устанавливаем Visual Studio Code с официального сайта - https://code.visualstudio.com/download/
Никаких особенностей в установке нет.

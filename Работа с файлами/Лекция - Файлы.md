## Введение - Работа с файлами

---
Все данные которые твоя программа хранит в переменных исчезают когда программа закрывается. Файлы решают эту проблему — они дают программе память между запусками. Сохранить результаты, прочитать конфигурацию, загрузить данные пользователя — без работы с файлами твоя программа живёт только один сеанс. JSON и CSV при этом — стандарты обмена данными которые используются повсюду. Научившись работать с файлами ты научился делать программы которые помнят.
___

### Зачем работать с файлами?

Переменные хранят данные только пока программа запущена. Файлы позволяют сохранять данные между запусками программы.

---

### Открытие файла

python

```python
file = open("file.txt", "r")   # открыть для чтения
file.close()                    # обязательно закрыть
```

Режимы открытия:

|Режим|Описание|
|---|---|
|`"r"`|Чтение — файл должен существовать|
|`"w"`|Запись — создаёт файл или перезаписывает существующий|
|`"a"`|Добавление — дописывает в конец файла|
|`"x"`|Создание — ошибка если файл уже существует|
|`"rb"`|Чтение в бинарном режиме|
|`"wb"`|Запись в бинарном режиме|

---

### Конструкция with

Лучший способ работать с файлами — файл закрывается автоматически:

python

```python
with open("file.txt", "r") as file:
    content = file.read()
# файл уже закрыт здесь
```

Даже если произойдёт ошибка — файл будет закрыт корректно.

### Чтение файла

python

```python
# read() — читает весь файл как одну строку
with open("file.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)

# readline() — читает одну строку
with open("file.txt", "r", encoding="utf-8") as file:
    line = file.readline()
    print(line)

# readlines() — читает все строки в список
with open("file.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()
    print(lines)   # ["строка1\n", "строка2\n", ...]

# перебор строк — самый питоновский способ
with open("file.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())   # strip() убирает \n
```

`encoding="utf-8"` — всегда указывай кодировку чтобы избежать проблем с русским текстом.

---

### Запись в файл

python

```python
# запись — перезаписывает файл
with open("file.txt", "w", encoding="utf-8") as file:
    file.write("Привет, мир!\n")
    file.write("Вторая строка\n")

# writelines() — записывает список строк
lines = ["строка 1\n", "строка 2\n", "строка 3\n"]
with open("file.txt", "w", encoding="utf-8") as file:
    file.writelines(lines)

# добавление в конец файла
with open("file.txt", "a", encoding="utf-8") as file:
    file.write("Новая строка\n")
```

### Обработка ошибок при работе с файлами

python

```python
try:
    with open("file.txt", "r", encoding="utf-8") as file:
        content = file.read()
except FileNotFoundError:
    print("Файл не найден")
except PermissionError:
    print("Нет доступа к файлу")
```

### Работа с JSON

JSON — популярный формат для хранения и передачи данных. Словари Python легко конвертируются в JSON.

python

```python
import json

# запись в JSON
person = {
    "name": "Иван",
    "age": 25,
    "hobbies": ["чтение", "программирование"]
}

with open("person.json", "w", encoding="utf-8") as file:
    json.dump(person, file, ensure_ascii=False, indent=4)

# чтение из JSON
with open("person.json", "r", encoding="utf-8") as file:
    data = json.load(file)
    print(data["name"])   # Иван
```

`ensure_ascii=False` — чтобы русские буквы не превращались в коды. `indent=4` — красивое форматирование с отступами.

### Работа с CSV

CSV — формат таблиц, каждая строка — запись, значения разделены запятой.

python

```python
import csv

# запись CSV
students = [
    ["Иван", 25, "Москва"],
    ["Мария", 22, "Питер"],
    ["Алексей", 27, "Казань"]
]

with open("students.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Имя", "Возраст", "Город"])   # заголовок
    writer.writerows(students)

# чтение CSV
with open("students.csv", "r", encoding="utf-8") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

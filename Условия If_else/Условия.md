Тема 1.5. - Условия (if _ elif _ else)

## Введение (if / elif / else)
---
Без условий программа — это просто список команд которые выполняются одинаково всегда. Условия дают программе интеллект — способность принимать решения. Показывать рекламу или нет, пускать пользователя на сайт или нет, давать скидку или нет — это всё условия. Любая логика любого приложения построена на ветвлениях. Это момент когда твой код перестаёт быть скриптом и начинает думать.
___
### Зачем нужны условия?

Условия позволяют программе принимать решения — выполнять разный код в зависимости от ситуации.

python

```python
age = 20

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

---

### Синтаксис

python

```python
if условие:
    # выполняется если условие True
elif другое_условие:
    # выполняется если первое False, а это True
else:
    # выполняется если все условия False
```

Важно — после `if`, `elif`, `else` ставится двоеточие, а код внутри обязательно с отступом (4 пробела или Tab).

---

### if

python

```python
temperature = 30

if temperature > 25:
    print("На улице жарко")
```

Если условие `False` — код внутри просто пропускается.

---

### if / else

python

```python
temperature = 15

if temperature > 25:
    print("На улице жарко")
else:
    print("На улице не жарко")
```

---

### if / elif / else

python

```python
temperature = 15

if temperature > 25:
    print("Жарко")
elif temperature > 15:
    print("Тепло")
elif temperature > 5:
    print("Прохладно")
else:
    print("Холодно")
```

`elif` можно писать сколько угодно. Python проверяет условия сверху вниз и останавливается на первом `True`.

---

### Вложенные условия

python

```python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("Добро пожаловать")
    else:
        print("Нет билета")
else:
    print("Вход только с 18 лет")
```

Вложенность лучше не делать глубже 2-3 уровней — код становится нечитаемым.

---

### Сложные условия

python

```python
age = 20
has_passport = True
is_banned = False

if age >= 18 and has_passport and not is_banned:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

---

### Тернарный оператор

Короткая запись if/else в одну строку:

python

```python
# обычная запись
if age >= 18:
    status = "взрослый"
else:
    status = "ребёнок"

# тернарная запись
status = "взрослый" if age >= 18 else "ребёнок"
print(status)
```

---

### Истинность значений

В Python любое значение можно использовать как условие:

python

```python
# False в условии:
if 0:       # False
if "":      # False — пустая строка
if []:      # False — пустой список
if None:    # False

# True в условии:
if 1:          # True
if "привет":   # True — непустая строка
if [1, 2]:     # True — непустой список
```

python

```python
name = ""

if name:
    print(f"Привет, {name}")
else:
    print("Имя не указано")
```

### Частые ошибки

python

```python
# Ошибка 1 — = вместо ==
if x = 5:    # ошибка синтаксиса
if x == 5:   # правильно

# Ошибка 2 — нет отступа
if x > 0:
print("положительное")   # ошибка — нужен отступ

# Ошибка 3 — сравнение с True/False напрямую
if is_active == True:    # работает, но не по-питоновски
if is_active:            # правильно

if is_active == False:   # работает, но не по-питоновски
if not is_active:        # правильно
```

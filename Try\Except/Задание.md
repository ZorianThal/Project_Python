### Задание

1. Напиши функцию `safe_divide(a, b)` которая:

- Возвращает результат деления
- При делении на ноль возвращает `"Ошибка: деление на ноль"`
- При передаче не числа возвращает `"Ошибка: неверный тип данных"`

2. Напиши программу которая просит пользователя вводить числа пока он не введёт корректное число. После ввода выводит его квадрат:

```
Введи число: привет
Это не число, попробуй снова
Введи число: 5
Квадрат числа 5 = 25
```

3. Напиши функцию `read_json(filename)` которая:

- Читает JSON файл и возвращает данные
- Если файл не найден — возвращает `"Файл не найден"`
- Если файл не является валидным JSON — возвращает `"Неверный формат JSON"`

4. Создай своё исключение `NegativeNumberError` и напиши функцию `square_root(n)` которая:

- Возвращает квадратный корень числа
- Вызывает `NegativeNumberError` если число отрицательное

Тема 1.3. - Операторы и выражения
## Введение
___
Хранить данные недостаточно — с ними нужно что-то делать. Операторы — это инструменты твоей программы. Сложить два числа, сравнить возраст пользователя с минимальным, проверить сразу несколько условий — всё это операторы. Без них программа была бы просто списком переменных которые никак не взаимодействуют друг с другом. Это арифметика программирования — базовая математика которая лежит в основе любой логики. 
___
### Что такое оператор?

Оператор — это символ или команда, которая выполняет действие над значениями. Значения, над которыми выполняется действие, называются **операндами**.

python

```python
10 + 5   # + это оператор, 10 и 5 это операнды
```

---

### Арифметические операторы

|Оператор|Действие|Пример|Результат|
|---|---|---|---|
|`+`|Сложение|`10 + 3`|`13`|
|`-`|Вычитание|`10 - 3`|`7`|
|`*`|Умножение|`10 * 3`|`30`|
|`/`|Деление|`10 / 3`|`3.3333...`|
|`//`|Целочисленное деление|`10 // 3`|`3`|
|`%`|Остаток от деления|`10 % 3`|`1`|
|`**`|Возведение в степень|`10 ** 3`|`1000`|

Важный момент — деление `/` всегда возвращает `float`:

python

```python
print(10 / 2)   # 5.0, не 5
print(10 // 2)  # 5
```

---

### Операторы сравнения

Возвращают `True` или `False`:

|Оператор|Смысл|Пример|Результат|
|---|---|---|---|
|`==`|Равно|`5 == 5`|`True`|
|`!=`|Не равно|`5 != 3`|`True`|
|`>`|Больше|`5 > 3`|`True`|
|`<`|Меньше|`5 < 3`|`False`|
|`>=`|Больше или равно|`5 >= 5`|`True`|
|`<=`|Меньше или равно|`3 <= 5`|`True`|

Частая ошибка:

python

```python
x = 5    # присваивание
x == 5   # сравнение — это разные вещи
```

---

### Логические операторы

|Оператор|Смысл|Пример|Результат|
|---|---|---|---|
|`and`|И (оба должны быть True)|`True and False`|`False`|
|`or`|ИЛИ (хотя бы одно True)|`True or False`|`True`|
|`not`|НЕ (инверсия)|`not True`|`False`|

python

```python
age = 20
is_student = True

print(age > 18 and is_student)   # True
print(age > 18 or is_student)    # True
print(not is_student)            # False
```

---

### Операторы присваивания

|Оператор|Пример|Равносильно|
|---|---|---|
|`=`|`x = 5`|`x = 5`|
|`+=`|`x += 3`|`x = x + 3`|
|`-=`|`x -= 3`|`x = x - 3`|
|`*=`|`x *= 3`|`x = x * 3`|
|`/=`|`x /= 3`|`x = x / 3`|
|`//=`|`x //= 3`|`x = x // 3`|
|`%=`|`x %= 3`|`x = x % 3`|
|`**=`|`x **= 3`|`x = x ** 3`|

python

```python
x = 10
x += 5   # x теперь 15
x *= 2   # x теперь 30
```

---

### Приоритет операторов

Python выполняет операции в определённом порядке — как в математике:

```
** > * / // % > + - > == != > > < >= <= > not > and > or
```

python

```python
print(2 + 3 * 4)      # 14, не 20 — сначала умножение
print((2 + 3) * 4)    # 20 — скобки меняют порядок
print(2 ** 3 ** 2)    # 512 — ** считается справа налево
```

Если сомневаешься в порядке — ставь скобки. Это делает код читаемее.

---

### Операторы принадлежности и тождественности

python

```python
# in / not in — есть ли элемент в последовательности
print("а" in "Привет")        # False
print("П" in "Привет")        # True
print(3 in [1, 2, 3, 4])      # True

# is / is not — один ли это объект в памяти
x = None
print(x is None)              # True
print(x is not None)          # False
```

`==` проверяет равенство значений, `is` проверяет что это один и тот же объект в памяти.

### Задание

1. Напиши программу которая берёт два числа `a = 17` и `b = 5` и выводит результат всех арифметических операций над ними с пояснением:

```
17 + 5 = 22
17 - 5 = 12
...
```

2. Даны переменные:

python

```python
age = 19
has_passport = True
is_banned = False
```

Напиши одно выражение которое проверяет: пользователь старше 18, имеет паспорт и не забанен. Выведи результат.

3. Что выведет этот код и почему — объясни каждую строку:

python

```python
x = 10
x += 5
x *= 2
x //= 3
print(x)
```

### Ответ - Задание 1

python

```python
a = 17
b = 5

print(f"{a} + {b} = {a + b}")   # 17 + 5 = 22
print(f"{a} - {b} = {a - b}")   # 17 - 5 = 12
print(f"{a} * {b} = {a * b}")   # 17 * 5 = 85
print(f"{a} / {b} = {a / b}")   # 17 / 5 = 3.4
print(f"{a} // {b} = {a // b}") # 17 // 5 = 3
print(f"{a} % {b} = {a % b}")   # 17 % 5 = 2
print(f"{a} ** {b} = {a ** b}") # 17 ** 5 = 1419857
```

---

### Ответ - Задание 2

python

```python
age = 19
has_passport = True
is_banned = False

result = age > 18 and has_passport and not is_banned
print(result)   # True
```

Разбор:

- `age > 18` — True, 19 больше 18
- `has_passport` — True
- `not is_banned` — not False = True
- `True and True and True` — True

---

### Ответ - Задание 3

python

```python
x = 10
x += 5    # x = 10 + 5 = 15
x *= 2    # x = 15 * 2 = 30
x //= 3   # x = 30 // 3 = 10
print(x)  # 10
```

Каждый шаг берёт текущее значение `x` и применяет операцию — результат сохраняется обратно в `x`.

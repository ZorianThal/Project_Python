# Switch-case в Python

## 1. Что такое switch-case

> [!note] Определение
> **Switch-case** это конструкция, которая сравнивает одно значение с несколькими вариантами и выполняет код того варианта, который совпал. Это замена длинной цепочки `if / elif / else`.

> [!info] Версии Python
> Оператор `match/case` доступен с **Python 3.10**. В более ранних версиях используют `if/elif` или словарь функций.

---

## 2. Как делали раньше

### Вариант 1: if / elif / else

```python
day = 3

if day == 1:
    name = "Понедельник"
elif day == 2:
    name = "Вторник"
elif day == 3:
    name = "Среда"
else:
    name = "Неизвестно"
```

### Вариант 2: словарь

```python
days = {1: "Понедельник", 2: "Вторник", 3: "Среда"}
name = days.get(day, "Неизвестно")   # get даёт значение по умолчанию
```

### Вариант 3: словарь функций (диспетчеризация)

```python
def add(a, b): return a + b
def sub(a, b): return a - b

operations = {"+": add, "-": sub}
result = operations["+"](5, 3)   # 8
```

---

## 3. Базовый синтаксис `match / case`

```python
day = 3

match day:
    case 1:
        print("Понедельник")
    case 2:
        print("Вторник")
    case 3:
        print("Среда")
    case _:
        print("Неизвестно")
```

> [!tip] Разбор
> - `match day:` выражение, которое сравниваем
> - `case 1:` образец (pattern); если совпал, выполняется блок
> - `case _:` **шаблон-заглушка** (wildcard), аналог `default`. Совпадает с чем угодно

> [!important] Отличия от switch в C / Java
> - **Нет `break`**: выполняется только первый совпавший `case`, «проваливания» (fallthrough) нет.
> - Проверка идёт **сверху вниз**, порядок важен.
> - Если ни один `case` не подошёл и нет `_`, ничего не произойдёт (ошибки не будет).

## 4. Виды паттернов

### 4.1 Литералы (числа, строки, `True`, `False`, `None`)

```python
match command:
    case "start":
        print("Запуск")
    case "stop":
        print("Остановка")
    case None:
        print("Команда не задана")
```

### 4.2 Несколько значений через `|` (ИЛИ)

```python
match day:
    case 6 | 7:
        print("Выходной")
    case 1 | 2 | 3 | 4 | 5:
        print("Рабочий день")
```

### 4.3 Захват значения (capture pattern)

Имя переменной в `case` **захватывает** значение:

```python
match command:
    case "quit":
        print("Выход")
    case other:                    # совпадёт с чем угодно, значение попадёт в other
        print(f"Неизвестная команда: {other}")
```

> [!warning] Главная ловушка
> Голое имя в `case` это **НЕ сравнение с переменной**, а **захват**. Оно всегда совпадает!
> ```python
> RED = "red"
> match color:
>     case RED:        # ОШИБКА: это не сравнение с RED, а присваивание color -> RED
>         ...
> ```
> Чтобы сравнивать с константой, используйте **имя с точкой** (например, `Color.RED`) или литерал.

### 4.4 Охранное условие (guard) через `if`

```python
match age:
    case n if n < 0:
        print("Ошибка")
    case n if n < 18:
        print("Несовершеннолетний")
    case _:
        print("Взрослый")
```

### 4.5 Последовательности (списки, кортежи)

```python
match point:
    case (0, 0):
        print("Начало координат")
    case (x, 0):
        print(f"На оси X, x = {x}")
    case (0, y):
        print(f"На оси Y, y = {y}")
    case (x, y):
        print(f"Точка ({x}, {y})")
```

Захват «остатка» через `*`:

```python
match command.split():
    case ["go", direction]:
        print(f"Идём: {direction}")
    case ["take", *items]:
        print(f"Берём: {items}")
    case ["quit"]:
        print("Выход")
    case _:
        print("Не понимаю")
```

> [!info] Строки не считаются последовательностями
> Паттерн `[a, b]` **не совпадёт** со строкой `"ab"`: `str`, `bytes` намеренно исключены.

### 4.6 Словари (mappings)

```python
match event:
    case {"type": "click", "x": x, "y": y}:
        print(f"Клик в ({x}, {y})")
    case {"type": "key", "key": k}:
        print(f"Нажата клавиша {k}")
```

> [!tip] Особенность
> Словарный паттерн совпадает, даже если в словаре есть **лишние ключи**. Нужны именно перечисленные. Остаток можно собрать через `**rest`.

### 4.7 Классы (class patterns)

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

match p:
    case Point(x=0, y=0):
        print("Начало координат")
    case Point(x=0):
        print("На оси Y")
    case Point(x, y):                  # позиционные: работает через __match_args__
        print(f"Точка ({x}, {y})")
```

> [!note] `__match_args__`
> Позиционные паттерны `Point(x, y)` работают, если в классе задан `__match_args__ = ("x", "y")`. `@dataclass` создаёт его **автоматически**.

Проверка типа:

```python
match value:
    case int():
        print("Целое")
    case str():
        print("Строка")
    case list():
        print("Список")
```

### 4.8 Подпаттерны и `as`

```python
match data:
    case [int() as a, int() as b]:
        print(a + b)
    case ("add" | "sum") as op:
        print(f"Операция: {op}")
```

### 4.9 Константы через Enum

```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2

match color:
    case Color.RED:        # имя с точкой = сравнение, а не захват
        print("Красный")
    case Color.GREEN:
        print("Зелёный")
```

## 5. Сводная таблица паттернов

| Паттерн | Пример | Что делает |
|---|---|---|
| Литерал | `case 42:` | Сравнение с константой |
| Заглушка | `case _:` | Совпадает с любым, не сохраняет |
| Захват | `case x:` | Совпадает с любым, сохраняет в `x` |
| Значение с точкой | `case Color.RED:` | Сравнение с константой по имени |
| ИЛИ | `case 1 \| 2:` | Любой из вариантов |
| Охрана | `case n if n > 0:` | Дополнительное условие |
| Последовательность | `case [a, b]:` | Список или кортеж из 2 элементов |
| С остатком | `case [a, *rest]:` | Первый элемент + остальные |
| Словарь | `case {"k": v}:` | Словарь с ключом `k` |
| Класс | `case Point(x=0):` | Объект класса с условием на атрибуты |
| `as` | `case int() as n:` | Сохранить совпавшее целиком |

## 6. Правила и ограничения

> [!warning] Что важно помнить
> 1. Неопровержимый паттерн (`_` или голое имя) должен стоять **последним**, иначе `SyntaxError`.
> 2. `|` нельзя использовать с паттернами, захватывающими **разные** имена.
> 3. Порядок `case` важен: первый совпавший побеждает.
> 4. `match` и `case` это **«мягкие» ключевые слова**: их можно использовать как имена переменных вне конструкции.
> 5. Для простого соответствия «ключ → значение» словарь часто быстрее и короче, чем `match`.

## 7. Когда что использовать

| Ситуация | Лучший инструмент |
|---|---|
| Простое отображение значения в значение | словарь `dict.get()` |
| 2-3 простых условия | `if / elif / else` |
| Много вариантов одной переменной | `match / case` |
| Разбор структуры (списки, словари, объекты) | `match / case` |
| Обработка команд, токенов, JSON-сообщений | `match / case` |
| Нужна совместимость с Python < 3.10 | `if/elif` или словарь |

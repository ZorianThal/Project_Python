Тема 1.2. - Переменные и типы данных
## Введение
___
Представь что ты строишь дом. Прежде чем класть кирпичи тебе нужны материалы — и где-то их хранить. Переменные — это склад твоей программы. Без них код не может запомнить ни одного значения. Ты не сможешь сохранить имя пользователя, счёт в игре, цену товара — ничего. Типы данных при этом говорят программе что именно хранится в каждой ячейке — число, текст, истина или ложь. Это фундамент без которого не существует ни одна программа на свете.
___
### Что такое переменная?

Представь переменную как **коробку с ярлыком**. Ярлык — это имя, внутри — значение.

python

```python
name = "Алексей"  # коробка с ярлыком "name", внутри "Алексей"
age = 25          # коробка "age", внутри 25
```

`=` — это не "равно" как в математике, а **оператор присваивания** — "положи это значение в эту переменную".

---
### Основные типы данных

#### int — целое число

python

```python
age = 25
year = 2024
temperature = -10
```

#### float — дробное число

python

```python
height = 1.75
pi = 3.14159
price = 99.99
```

#### str — строка (текст)

python

```python
name = "Алексей"
city = 'Москва'      # можно одинарные кавычки
message = "Привет!"
```

#### bool — булево значение

python

```python
is_student = True
is_married = False
```

Только два значения: `True` или `False`. Всегда с большой буквы.

#### None — пустое значение

python

```python
result = None  # переменная есть, но значения пока нет
```

Используется когда значение неизвестно или отсутствует.

---
### Как узнать тип переменной

python

```python
x = 42
print(type(x))        # <class 'int'>

name = "Иван"
print(type(name))     # <class 'str'>

pi = 3.14
print(type(pi))       # <class 'float'>

flag = True
print(type(flag))     # <class 'bool'>
```

---
### Преобразование типов

Иногда нужно превратить один тип в другой:

python

```python
# str → int
x = "10"
y = int(x)      # y = 10

# int → float
a = 5
b = float(a)    # b = 5.0

# int → str
age = 25
s = str(age)    # s = "25"

# str → float
n = "3.14"
f = float(n)    # f = 3.14
```

Не всё можно конвертировать:

python

```python
int("привет")   #  ошибка — это не число
int("3.14")     #  ошибка — сначала нужно float()
int(float("3.14"))  #  = 3
```

---
### Конкатенация строк

Строки нельзя складывать с числами напрямую:

python

```python
print("Мне " + 25 + " лет")        # ошибка
print("Мне " + str(25) + " лет")   # "Мне 25 лет"
```

Удобнее использовать **f-строки**:

python

```python
age = 25
print(f"Мне {age} лет")   # "Мне 25 лет"
```

---
### Множественное присваивание

python

```python
a, b, c = 1, 2, 3       # a=1, b=2, c=3
x = y = z = 0            # все три равны 0

# Обмен значений — очень по-питоновски:
a, b = b, a
```

---
### Правила именования переменных

python

```python
# Правильно
my_name = "Иван"
user_age = 25
is_active = True

# Нельзя
2name = "Иван"      # начинается с цифры
my-name = "Иван"    # дефис запрещён
class = "А"         # class — зарезервированное слово Python
```

Стандарт в Python — **snake_case**: слова через нижнее подчёркивание, всё строчными буквами.

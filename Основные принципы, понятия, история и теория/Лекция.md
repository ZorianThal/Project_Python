### История
Python создал **Гвидо ван Россум** — нидерландский программист. В конце 1980-х он работал над языком ABC и хотел сделать что-то лучше — проще, читаемее, мощнее.

![[Pasted image 20260609142915.png]]

- **1991** — вышла первая версия Python 0.9.0
- **2000** — Python 2.0 (долгое время был стандартом)
- **2008** — Python 3.0 (текущая ветка, несовместима с Python 2)
- **2020** — Python 2 официально умер, все перешли на Python 3

Название — не в честь змеи. Гвидо был фанатом британского комедийного шоу **Monty Python's Flying Circus**.

### Философия Python

В Python встроена философия — можно прочитать прямо в коде:

python

```python
import this
```

Выведет **"Дзен Python"** — 19 принципов. Вот главные:

> _Красивое лучше уродливого_ _Явное лучше неявного_ _Простое лучше сложного_ _Читаемость имеет значение_

Это не просто слова — весь язык построен вокруг этих идей.

### Ключевые особенности языка

#### 1. Читаемость — главный приоритет

Python заставляет писать аккуратно через **отступы**. Блок кода определяется не скобками, а отступами:

python

```python
# В большинстве языков:
if (x > 0) {
    print("положительное");
}

# В Python:
if x > 0:
    print("положительное")
```

#### 2. Динамическая типизация

Не нужно объявлять тип переменной — Python сам разберётся:

python

```python
# Java:
int x = 5;

# Python:
x = 5  # просто присваиваешь
```

#### 3. Интерпретируемый язык

Код не компилируется заранее — он выполняется **строка за строкой** в реальном времени. Это удобно для обучения и отладки.

```
Твой код → Интерпретатор Python → Результат
```

#### 4. Мультипарадигменный

Python поддерживает разные стили программирования:

|Парадигма|Суть|
|---|---|
|**Процедурный**|пишешь шаги по порядку|
|**Объектно-ориентированный**|код организован в классы и объекты|
|**Функциональный**|функции как основной инструмент|

#### 5. Батарейки включены

Огромная стандартная библиотека — масса инструментов "из коробки", без установки:

python

```python
import math        # математика
import datetime    # дата и время
import random      # случайные числа
import os          # работа с файлами
```

#### 6. Огромная экосистема

Более **400 000 библиотек** в открытом доступе. Нужно что угодно — скорее всего уже написано.

### Как работает Python под капотом

```
Твой .py файл
      ↓
Интерпретатор читает код
      ↓
Преобразует в байт-код (.pyc)
      ↓
Виртуальная машина Python (CPython) исполняет байт-код
      ↓
Результат на экране
```

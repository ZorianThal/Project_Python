Тема 1.7. - Функции
## Введение - Функции

---
Представь что каждый раз когда тебе нужно заварить чай ты заново изобретаешь чайник. Функции решают эту проблему — написал один раз, используешь везде. Но это не просто удобство. Функции делают код читаемым, тестируемым и поддерживаемым. Любой профессиональный код состоит из функций. Без них программа превращается в один огромный нечитаемый блок. Функции — это первый шаг к тому чтобы писать код как настоящий разработчик.
___
### Что такое функция?

Функция — это именованный блок кода который можно вызывать многократно. Вместо того чтобы писать один и тот же код несколько раз — пишешь его один раз внутри функции и вызываешь когда нужно.

python

```python
def greet():
    print("Привет!")

greet()   # Привет!
greet()   # Привет!
```

---

### Синтаксис

python

```python
def имя_функции(параметры):
    # тело функции
    return результат
```

- `def` — ключевое слово для объявления функции
- имя пишется в `snake_case`
- `return` — возвращает значение из функции

---

### Параметры и аргументы

python

```python
def greet(name):        # name — параметр
    print(f"Привет, {name}!")

greet("Иван")           # "Иван" — аргумент
greet("Мария")
```

Параметр — это переменная в определении функции. Аргумент — это значение которое передаётся при вызове.

---

### return

python

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)   # 8
```

Без `return` функция возвращает `None`:

python

```python
def greet(name):
    print(f"Привет, {name}!")

result = greet("Иван")
print(result)   # None
```

`return` также останавливает выполнение функции:

python

```python
def check(x):
    if x < 0:
        return "отрицательное"
    if x == 0:
        return "ноль"
    return "положительное"
```

---

### Значения по умолчанию

python

```python
def greet(name, greeting="Привет"):
    print(f"{greeting}, {name}!")

greet("Иван")              # Привет, Иван!
greet("Иван", "Здравствуй")  # Здравствуй, Иван!
```

Параметры со значениями по умолчанию всегда идут после обычных параметров.

### Именованные аргументы

python

```python
def person_info(name, age, city):
    print(f"{name}, {age} лет, {city}")

person_info("Иван", 25, "Москва")                  # по порядку
person_info(age=25, city="Москва", name="Иван")    # по имени — порядок не важен
person_info("Иван", city="Москва", age=25)         # смешанный вариант
```

### *args — произвольное количество аргументов

python

```python
def total(*args):
    result = 0
    for num in args:
        result += num
    return result

print(total(1, 2, 3))        # 6
print(total(1, 2, 3, 4, 5))  # 15
```

`args` внутри функции — это кортеж всех переданных аргументов.

---

### **kwargs — именованные аргументы произвольно

python

```python
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Иван", age=25, city="Москва")
# name: Иван
# age: 25
# city: Москва
```

`kwargs` внутри функции — это словарь.

### Область видимости переменных

python

```python
x = 10   # глобальная переменная

def my_func():
    x = 20   # локальная переменная — не влияет на глобальную
    print(x) # 20

my_func()
print(x)     # 10
```

Переменная созданная внутри функции — локальная, снаружи недоступна:

python

```python
def my_func():
    y = 5

my_func()
print(y)   # ошибка — y не существует снаружи
```

Если нужно изменить глобальную переменную изнутри функции:

python

```python
x = 10

def my_func():
    global x
    x = 20

my_func()
print(x)   # 20
```

Использовать `global` стоит редко — это считается плохой практикой.

### Функции как объекты

В Python функция — это объект. Её можно передавать как аргумент:

python

```python
def square(x):
    return x ** 2

def apply(func, value):
    return func(value)

print(apply(square, 5))   # 25
```

---

### lambda — анонимные функции

Короткая функция в одну строку без имени:

python

```python
# обычная функция
def square(x):
    return x ** 2

# lambda
square = lambda x: x ** 2
print(square(5))   # 25

# lambda с двумя параметрами
add = lambda a, b: a + b
print(add(3, 4))   # 7
```

Lambda используется когда функция простая и нужна один раз.

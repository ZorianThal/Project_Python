Тема 1.4. - Строки
## Введение
---
Почти любая программа работает с текстом. Имена пользователей, сообщения, адреса, пароли, интерфейс — всё это строки. Умение работать со строками — это умение общаться с пользователем. Найти слово в тексте, обрезать лишние пробелы, разбить предложение на слова, красиво вывести результат — без этих навыков ты не сможешь написать даже простой чат-бот или форму регистрации. Строки — это язык которым программа разговаривает с человеком.
___
### Что такое строка?

Строка (`str`) — это последовательность символов. Любой текст в Python — это строка.

python

```python
name = "Алексей"
city = 'Москва'
message = """Это
многострочная
строка"""
```

Можно использовать одинарные `'`, двойные `"` или тройные `"""` кавычки.

---

### Индексация

Каждый символ строки имеет свой индекс. Индексация начинается с `0`.

python

```python
name = "Привет"
print(name[0])   # П
print(name[1])   # р
print(name[-1])  # т — отрицательный индекс с конца
print(name[-2])  # е
```

```
П  р  и  в  е  т
0  1  2  3  4  5
-6 -5 -4 -3 -2 -1
```

---

### Срезы (slicing)

Позволяют взять часть строки:

python

```python
# строка[начало:конец:шаг]
name = "Привет"

print(name[1:4])    # рив — с 1 по 3 (4 не включается)
print(name[:3])     # При — с начала до 3
print(name[3:])     # вет — с 3 до конца
print(name[::2])    # Пiet — каждый второй символ
print(name[::-1])   # тевирП — строка наоборот
```

### Основные методы строк

#### Регистр

python

```python
s = "привет мир"
print(s.upper())       # ПРИВЕТ МИР
print(s.lower())       # привет мир
print(s.capitalize())  # Привет мир
print(s.title())       # Привет Мир
```

#### Поиск и замена

python

```python
s = "привет мир"
print(s.find("мир"))      # 7 — индекс где начинается
print(s.find("пока"))     # -1 — не найдено
print(s.replace("мир", "питон"))  # привет питон
print(s.count("и"))       # 2 — сколько раз встречается
```

#### Проверки

python

```python
print("123".isdigit())     # True — только цифры
print("abc".isalpha())     # True — только буквы
print("  ".isspace())      # True — только пробелы
print("Привет".startswith("При"))  # True
print("Привет".endswith("вет"))    # True
```

#### Пробелы

python

```python
s = "  привет  "
print(s.strip())    # "привет" — убирает с обеих сторон
print(s.lstrip())   # "привет  " — только слева
print(s.rstrip())   # "  привет" — только справа
```

#### Разбивка и склейка

python

```python
s = "яблоко,груша,банан"
fruits = s.split(",")       # ["яблоко", "груша", "банан"]

words = ["привет", "мир"]
print(" ".join(words))      # "привет мир"
print("-".join(words))      # "привет-мир"
```

### Форматирование строк

#### f-строки (рекомендуемый способ)

python

```python
name = "Иван"
age = 25
print(f"Меня зовут {name}, мне {age} лет")

# Можно писать выражения прямо внутри
print(f"Через 5 лет мне будет {age + 5} лет")
print(f"Имя заглавными: {name.upper()}")
```

#### format()

python

```python
print("Меня зовут {}, мне {} лет".format("Иван", 25))
print("Меня зовут {name}, мне {age} лет".format(name="Иван", age=25))
```

#### % — старый способ (можно встретить в старом коде)

python

```python
print("Меня зовут %s, мне %d лет" % ("Иван", 25))
```

### Спецсимволы

|Символ|Смысл|
|---|---|
|`\n`|Перенос строки|
|`\t`|Табуляция|
|`\\`|Обратный слеш|
|`\"`|Кавычка внутри строки|

python

```python
print("Привет\nМир")   # Привет
                        # Мир
print("Имя:\tИван")    # Имя:    Иван
```

#### Сырые строки

python

```python
path = r"C:\Users\name\documents"  # r — игнорирует спецсимволы
print(path)  # C:\Users\name\documents
```

### Строка — это последовательность

python

```python
name = "Привет"

print(len(name))          # 6 — длина строки
print("П" in name)        # True
print("п" in name)        # False — регистр важен

for char in name:
    print(char)           # выводит каждый символ
```

---

### Неизменяемость строк

Строку нельзя изменить — можно только создать новую:

python

```python
name = "Привет"
name[0] = "п"   # ошибка — строки неизменяемы

name = "п" + name[1:]  # создаём новую строку
print(name)  # привет
```

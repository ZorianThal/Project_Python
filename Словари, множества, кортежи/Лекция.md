## Введение Словари, множества, кортежи
___
Список хорош когда важен порядок. Но часто тебе нужно не просто хранить данные а связывать их между собой — имя и возраст, товар и цену, пользователь и его настройки. Словарь делает именно это. Множество нужно когда важна уникальность — убрать дубликаты, найти пересечения. Кортеж — когда данные не должны меняться. Это три разных инструмента для трёх разных задач. Профессиональный разработчик знает когда использовать каждый из них — и это сразу видно в качестве его кода.
___

### Словарь (dict)

Словарь — это коллекция пар **ключ: значение**. Ключи уникальны, значения могут повторяться.

python

```python
person = {
    "name": "Иван",
    "age": 25,
    "city": "Москва"
}
```

#### Обращение к значениям

python

```python
print(person["name"])          # Иван
print(person.get("age"))       # 25
print(person.get("phone"))     # None — не вызывает ошибку
print(person.get("phone", "не указан"))  # не указан — значение по умолчанию
```

Разница между `[]` и `.get()` — если ключа нет, `[]` вызывает ошибку, `.get()` возвращает `None`.

#### Добавление и изменение

python

```python
person["email"] = "ivan@mail.ru"   # добавляет новый ключ
person["age"] = 26                  # изменяет существующий
```

#### Удаление

python

```python
del person["city"]           # удаляет по ключу
person.pop("age")            # удаляет и возвращает значение
person.clear()               # очищает словарь
```

#### Основные методы

python

```python
person = {"name": "Иван", "age": 25, "city": "Москва"}

print(person.keys())    # dict_keys(["name", "age", "city"])
print(person.values())  # dict_values(["Иван", 25, "Москва"])
print(person.items())   # dict_items([("name", "Иван"), ...])

print("name" in person)   # True — проверка ключа
print("Иван" in person.values())  # True — проверка значения
```

#### Перебор словаря

python

```python
for key in person:
    print(key)

for key, value in person.items():
    print(f"{key}: {value}")
```

#### Словарное включение

python

```python
squares = {i: i ** 2 for i in range(1, 6)}
print(squares)   # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

### Кортеж (tuple)

Кортеж — это как список, но **неизменяемый**. Используется когда данные не должны меняться.

python

```python
coordinates = (55.75, 37.61)
colors = ("red", "green", "blue")
single = (42,)   # кортеж из одного элемента — запятая обязательна
empty = ()
```

#### Операции с кортежем

python

```python
colors = ("red", "green", "blue")

print(colors[0])      # red
print(colors[-1])     # blue
print(colors[1:])     # ("green", "blue")
print(len(colors))    # 3
print("red" in colors)  # True

# изменить нельзя
colors[0] = "yellow"  # ошибка
```

#### Распаковка

python

```python
coordinates = (55.75, 37.61)
lat, lon = coordinates
print(lat)   # 55.75
print(lon)   # 37.61

# расширенная распаковка
first, *rest = (1, 2, 3, 4, 5)
print(first)  # 1
print(rest)   # [2, 3, 4, 5]
```

#### Когда использовать кортеж вместо списка

- Данные не должны меняться — координаты, RGB цвета, дни недели
- Кортеж быстрее списка
- Кортеж можно использовать как ключ словаря, список нельзя

python

```python
locations = {
    (55.75, 37.61): "Москва",
    (59.93, 30.32): "Санкт-Петербург"
}
```

### Множество (set)

Множество — это коллекция **уникальных** неупорядоченных элементов.

python

```python
fruits = {"яблоко", "груша", "банан", "яблоко"}
print(fruits)   # {"яблоко", "груша", "банан"} — дубликат удалён
```

#### Основные операции

python

```python
fruits = {"яблоко", "груша", "банан"}

fruits.add("манго")        # добавляет элемент
fruits.remove("груша")     # удаляет — ошибка если нет
fruits.discard("груша")    # удаляет — без ошибки если нет
fruits.pop()               # удаляет случайный элемент
fruits.clear()             # очищает
```

#### Математические операции над множествами

python

```python
a = {1, 2, 3, 4, 5}
b = {3, 4, 5, 6, 7}

print(a | b)   # объединение  {1, 2, 3, 4, 5, 6, 7}
print(a & b)   # пересечение  {3, 4, 5}
print(a - b)   # разность     {1, 2}
print(a ^ b)   # симметричная разность {1, 2, 6, 7}
```

#### Проверка вхождения

python

```python
print("яблоко" in fruits)   # True — работает быстрее чем в списке
```

#### Главное применение множеств — удаление дубликатов

python

```python
numbers = [1, 2, 2, 3, 3, 3, 4]
unique = list(set(numbers))
print(unique)   # [1, 2, 3, 4]
```

### Сравнение коллекций

||list|tuple|dict|set|
|---|---|---|---|---|
|Упорядоченность|да|да|да (Python 3.7+)|нет|
|Изменяемость|да|нет|да|да|
|Дубликаты|да|да|ключи уникальны|нет|
|Индексация|да|да|по ключу|нет|
|Применение|общий список|неизменяемые данные|пары ключ-значение|уникальные элементы|
